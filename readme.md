# News Explorer - Proyecto Full Stack

Un explorador de noticias interactivo donde los usuarios pueden buscar artículos recientes sobre cualquier tema, crear una cuenta y guardar sus noticias favoritas en su perfil personal.

## 🚀 Enlaces del Proyecto Desplegado

- **Frontend (Aplicación Web):** [https://news-explorer-8gqlfx65c-aten7.vercel.app](https://news-explorer-8gqlfx65c-aten7.vercel.app)
- **Backend (API URL):** [https://news-explorer-api-gc3x.onrender.com](https://news-explorer-api-gc3x.onrender.com)

## 🛠️ Tecnologías y Herramientas Utilizadas

**Frontend:**

- React
- Vite
- CSS (Metodología BEM)
- Despliegue en Vercel

**Backend:**

- Node.js
- Express.js
- MongoDB Atlas (Base de datos en la nube)
- JSON Web Tokens (JWT) para autenticación
- Despliegue en Render

**Integraciones de Terceros:**

- NewsAPI (Consultas de noticias a través de servidor proxy)

## ⚙️ Funcionalidades Principales

- **Búsqueda de Noticias:** Integración con API de noticias para buscar artículos de los últimos 7 días.
- **Autenticación de Usuarios:** Sistema de registro e inicio de sesión seguro con contraseñas encriptadas y tokens JWT.
- **Gestión de Artículos:** Los usuarios autenticados pueden guardar artículos en su perfil y eliminarlos cuando lo deseen.
- **Rutas Protegidas:** Acceso restringido a la sección de "Artículos Guardados" únicamente para usuarios con sesión iniciada.
- **Diseño Responsivo:** Interfaz adaptada para dispositivos móviles, tablets y pantallas de escritorio.
